Validación GPS y seguimiento de vehículos en tiempo real para flotas de transporte y servicio de campo.

FieldBeacon conecta el hardware en vehículo con su sistema de despacho, para que sepa exactamente cuándo llegó un vehículo —y si la actividad cuenta como completada.

Solicitar una demo

El problema

Las flotas pierden visibilidad en cuanto su sistema de telemática, despacho y servicio de campo dejan de hablarse. Las llegadas se registran tarde. Los ETA al cliente se desvían. Las penalizaciones de SLA se acumulan.

FieldBeacon cierra ese bucle en tiempo real —directamente desde el vehículo a su sistema de despacho.

Estados de validación en tiempo real

Cada llegada se reporta con un estado claro:

OK   el vehículo llegó dentro de la geocerca y a tiempo.

WARNING   el vehículo llegó pero tarde o al límite.

NOK   el vehículo nunca alcanzó el sitio.

ERROR   corte de telemetría o fallo del dispositivo.

Qué hace FieldBeacon

Una sola plataforma, cuatro funciones.

Seguimiento de vehículos en vivo

Posición actualizada cada minuto y eventos de entrada/salida de geocercas.

Validación de llegadas

Estados automáticos OK / WARNING / NOK / ERROR reportados a su sistema de despacho.

Telemetría resiliente offline

Los dispositivos almacenan en MicroSD cuando hay corte de cobertura y vuelcan al reconectar. Sin pérdida de datos.

Abierto e integrable

APIs REST + WebSocket, backend open-source, desplegable en su VPC o en la nuestra.

El hardware

Un dispositivo telemático en vehículo robusto, con marca ST3AM y listo para instalar. Se conecta al puerto OBD-II y se alimenta desde el propio vehículo.

ConectividadGNSS + 4G LTE
Interfaz de vehículoOBD-II + GPIO
Búfer offlineMicroSD (auto-volcado al reconectar)
Alimentación9–36 V desde el vehículo
CarcasaGrado IP para uso en vehículo
ComunicacionesTLS hacia la nube FieldBeacon, claves API hasheadas

Cómo encaja todo

Vehículo → nube → su despacho. Tres pasos, sin middleware que mantener.

Dispositivo en vehículo

Telemetría GPS + OBD-II, búfer MicroSD, subida TLS.

→
Nube FieldBeacon

PostGIS + TimescaleDB, evaluación de geocercas, streaming WebSocket en tiempo real.

→
Su despacho / OFS

Estados de validación enviados vía REST o el plugin nativo de Oracle Field Service.

Integraciones

Diseñado para encajar en los sistemas que ya opera.

Oracle Field Service

Plugin nativo de validación vía geowatch-agent. OFS recibe los estados OK / WARNING / NOK / ERROR de fábrica.

APIs REST + WebSocket

Integración genérica de despacho para cualquier consumidor —empuje de telemetría en tiempo real a sus propios sistemas.

Dashboards

UI de administración integrada para supervisores de flota. Más exportaciones para la herramienta BI que prefiera.

Confianza y despliegue

Seguro por diseño

TLS para todas las comunicaciones del dispositivo. Claves API almacenadas hasheadas, nunca en texto plano. Rate limiting por dispositivo.

Aislamiento multi-tenant

Aislamiento por esquema en PostgreSQL compartido. Los datos de su flota se quedan dentro de su tenant.

Despliegue a su manera

Docker Compose o Kubernetes. Ejecútelo en nuestra nube, en su VPC o totalmente on-premise.
