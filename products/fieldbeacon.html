Real-time GPS validation and vehicle tracking for transportation and field-service fleets.

FieldBeacon connects in-vehicle hardware to your dispatch system, so you know exactly when a vehicle arrived — and whether the activity counts as completed.

Request a demo

The problem

Fleets lose visibility the moment their telematics, dispatch and field-service systems don't talk to each other. Arrivals get logged late. Customer ETAs drift. SLA penalties pile up.

FieldBeacon closes that loop in real time — straight from the vehicle to your dispatch.

Real-time validation states

Every arrival is reported with a clear state:

OK   vehicle arrived inside the geofence within window.

WARNING   vehicle arrived but late or marginal.

NOK   vehicle never reached the site.

ERROR   telemetry gap or device fault.

What FieldBeacon does

A single platform, four jobs.

Live vehicle tracking

Sub-minute position updates and geofence entry/exit events.

Arrival validation

Automatic OK / WARNING / NOK / ERROR states reported back to your dispatch system.

Offline-resilient telemetry

Devices buffer to MicroSD when cellular drops and flush on reconnect. No data loss.

Open & integrable

REST + WebSocket APIs, open-source backend, deployable in your VPC or ours.

The hardware

A ruggedized in-vehicle telematics device, ST3AM-branded and ready to install. Plugs into the OBD-II port and powers from the vehicle.

ConnectivityGNSS + 4G LTE
Vehicle interfaceOBD-II + GPIO
Offline bufferMicroSD (auto-flush on reconnect)
Power9–36 V vehicle power
EnclosureIP-rated for in-vehicle use
CommsTLS to FieldBeacon cloud, hashed API keys

How it fits together

Vehicle → cloud → your dispatch. Three steps, no middleware to maintain.

In-vehicle device

GPS + OBD-II telemetry, MicroSD buffering, TLS upload.

→
FieldBeacon cloud

PostGIS + TimescaleDB, geofence evaluation, real-time WebSocket streaming.

→
Your dispatch / OFS

Validation states pushed back via REST or the native Oracle Field Service plugin.

Integrations

Built to slot into the systems you already operate.

Oracle Field Service

Native validation plugin via the geowatch-agent. OFS receives OK / WARNING / NOK / ERROR states out of the box.

REST + WebSocket APIs

Generic dispatch integration for any consumer — push real-time telemetry into your own systems.

Dashboards

Built-in admin UI for fleet supervisors. Plus exports for the BI tool of your choice.

Trust & deployment

Secure by design

TLS for all device communications. API keys stored hashed, never plaintext. Per-device rate limiting.

Multi-tenant isolation

Schema-per-environment isolation on shared PostgreSQL. Fleet data stays inside your tenant.

Deploy your way

Docker Compose or Kubernetes. Run it in our cloud, your VPC, or fully on-premise.
